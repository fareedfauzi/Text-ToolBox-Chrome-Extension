# Text-ToolBox-Chrome-Extension
Vibe coded source codes for a text toolbox chrome extension.

Text Utility Tool is a lightweight, privacy-friendly Chrome extension for developers, analysts, and power users.

Features:
- Deduplicate
- Sort lines
- Undo
- Plain text find & replace
- Regex replace & regex remove
- Remove characters
- Base64 encode / decode
- URL encode / decode
- JSON beautifier with validation
- Upper / lower case conversion
- Dark mode support
